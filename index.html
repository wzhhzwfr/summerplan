WHAT WE LEARNED

比“打卡”更重要的三个答案

A

湿地是一张关系网

水体、植被、候鸟、麋鹿和人类活动彼此关联。保护某一种生命，最终要回到完整生境。

B

采样不等于得出结论

没有规范检测，就不把颜色、气味和水面状态写成水质等级。克制也是实践能力的一部分。

C

观察可以继续长成方案

实地问题意识与公开数据、技术指南相结合，可以形成一套可被讨论、后续可验证的本地治理构想。

LOCAL LENS

三张港城照片，三种身边水环境

照片负责提出问题，规范监测负责验证问题，治理构想负责回应问题。

近岸海域：把潮汐和盐度放进判断

近岸海域连接港口、城市与山海景观。全市或海湾尺度的公开评价可以提供背景，却不能替代对某一岸段、某一时刻的具体判断。

我们设想的下一步记录潮位、潮相、降雨与盐度或电导率，关注入海河流和排口；咸淡水交汇场景不直接套用普通淡水参考线。

公共活动水域：水环境也是校园生活

龙舟活动让水面成为连接师生、社区与城市文化的公共空间。保护水环境，也是在守护安全、整洁而可亲近的日常生活。

我们设想的下一步活动前排查岸线与水面，活动中设置减塑和垃圾回收提示，活动后清洁并用固定照片复查，形成可持续的活动水域档案。

校园周边河道：照片先提出问题

照片可见局部水面覆盖和漂浮物现象，但外观不能说明污染来源，也不能据此判定水质类别。它更适合作为一次待核实的问题记录。

我们设想的下一步先记录时间、天气、入排水口、水体交换和岸边活动，再按规范测定；治理从控源、清理、水系连通与岸带缓冲开始。
影像边界

LOCAL GOVERNANCE CONCEPT

连云港小微水体低动力协同治理参考方案

成果性质

公开资料支撑的概念方案。尚未完成场地勘察、工程设计或实测验证，不作为施工图与治理成效承诺。

01

源头减量

先查雨污混接、施肥与养殖投喂，能不进入水体的负荷先在源头减少。

02

乡土草带

沿岸留出连续缓冲带，减缓地表径流并截留泥沙和颗粒态磷。

03

生态沟渠

利用缓坡、植物和砾石增加接触时间，同时保留排涝通道。

04

沉淀前池

在湿地前先拦大颗粒悬浮物，设置便于清淤的独立单元。

05

浅水旁路湿地

让部分水流经浅水植物—基质—微生物系统，主河道不被强行阻断。

06

复氧

优先利用自然跌水；低溶氧风险时，再按需使用太阳能曝气。

07

回用或排放

优先回用于绿化或农灌；排放前仍需按适用要求监测确认。

HOW IT WORKS

不是“种点水草”，而是让每个单元承担一种任务

01

拦截与减速

草带和缓坡先降低径流速度，把泥沙、枯落物与附着其上的污染物挡在水体之外。

02

沉淀与便捷维护

前池承担“脏活”，集中沉积较大颗粒；可达、可清淤比造型复杂更重要。

03

植物—基质—微生物协同

植物提供根区和生境，基质吸附与过滤，微生物参与有机物降解和氮转化。

04

复氧与水力调节

跌水、浅滩和必要时曝气改善气水交换；旁路与溢流口兼顾停留时间和暴雨安全。

THREE LOCAL SCENARIOS

从身边场景出发，给出不同适配

先识别水体，再决定指标、植物、水力与运维方式。

CAMPUS RIVER

校园及城市小河

主要问题
水体交换慢，雨后径流、生活垃圾、入排水口和岸边硬化可能共同影响局部水面状态。
建议路径
排口排查与垃圾拦截 → 乡土草本缓冲 → 沉淀前池 → 旁路浅水湿地 → 自然跌水 / 按需复氧。
勘察重点
固定点位记录天气与水位，现场关注DO、pH、水温、电导率和透明度；需要下结论时再规范送检氮磷等指标。

PUBLIC WATERSPACE

公共活动水域

主要问题
亲水活动、赛事和休闲增加了岸线使用强度，也带来水面保洁、垃圾管理与安全巡查需求。
建议路径
活动前巡查 → 岸线减塑与分类回收 → 活动后水面清洁 → 固定照片复查 → 异常情况转交专业部门。
勘察重点
把水质保护、岸线安全与公众体验一起管理；不因水面看起来清澈就省略日常巡查。

TIDAL / BRACKISH

沿海或感潮半咸水

主要问题
盐度与潮位变化会影响植物、材料和指标解释，咸淡水倒灌风险更高。
建议路径
控源 → 防倒灌与潮位调节 → 耐盐乡土植物带 → 可旁路湿地 → 安全出水。
勘察重点
增加盐度 / 电导率、潮位和潮相记录；不用淡水Ⅲ类参考线直接评价半咸水。

NEXT VALIDATION

如果要把方案做成下一轮小试

先统一方法与记录，再谈“净化效果”。

现场勘察

  • 水体用途、进出水口、雨污口、潮汐或排涝要求
  • 岸坡、可用空间、暴雨溢流路径和运维通道
  • 便携式pH / DO / 水温 / 电导率仪，校准液与记录表
  • 采样瓶、标签、手套、冷藏箱、空白样与平行样计划

实验室与记录

  • 提前确认实验室可测氨氮、TP、TN、CODMn的标准方法
  • 统一采样时间、深度、容器、保存方式和送检时限
  • 建立样品编号、交接人、照片、坐标和天气记录
  • 设置质控样；不要把试纸或肉眼观察写成正式检测值

小试材料

  • 透明水槽或周转箱、量筒、定时器、软管和可调小泵
  • 砾石、粗砂、沉淀杯、乡土非入侵草本与固定网
  • 相同来源的模拟水或同一批原水，统一体积与初始值
  • 每组独立编号；若要比较，预留至少3个平行重复

FOUR-GROUP DISPLAY

四组原理展示建议

同一批水、同一体积、同一时间，逐级增加处理单元。

A

原水静置

只观察自然沉降，作为原理展示的参照。

B

草带拦截

水流先通过带根草皮或仿真草带，观察流速与悬浮物变化。

C

草带 + 沟渠 + 前池

增加砾石沟和沉淀单元，展示分段承担任务的思路。

D

完整协同链

在C组后增加浅水植物湿地与小跌水，展示组合流程。

名称边界：

如果A—D每组只搭1套、没有独立平行重复，它只能叫“原理展示”或“课程小试”，不能写成“实验验证了净化效果”。若要做可比较实验，建议每组至少3个独立重复，并统一初始水质、体积、流量、停留时间与检测方法。
