# 林海相依｜盐城实践与港城小微水体治理构想

江苏海洋大学“林海相依”实践团社会实践成果网页。

页面保留盐城两日真实实践主线：黄海湿地博物馆参观与采访、竹林大饭店与盐镇水街城市文化体验、中华麋鹿园生境观察，以及景观湖和相邻排水沟的两份水样记录。两份水样未送实验室，页面不据此展示pH、溶解氧、氮磷数据或评价水质等级。

在真实记录基础上，网页新增“连云港小微水体低动力协同治理”成果模块：

- “源头减量—乡土草带—生态沟渠—沉淀前池—浅水旁路湿地—自然跌水 / 按需太阳能曝气—回用或排放”流程；
- 城市池塘、农村排水沟、沿海或感潮半咸水三类适配场景；
- pH、DO、氨氮、总磷、CODMn的Ⅲ类单指标参考工具；
- 连云港年度、规划背景与月度公开数据卡，以及石梁河、东海农田退水、赣榆“三池两坝一湿地”案例；
- 现场勘察、规范采样、实验室检测和四组原理展示准备清单；
- GB 3838、HJ 91.2、人工湿地与河湖缓冲带指南等来源链接。

治理模块属于基于公开资料形成的概念参考方案，尚未完成场地勘察、工程设计或实测验证；交互工具只作单指标筛查，不构成水质评级。
