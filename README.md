# 林海相依｜盐城湿地实践与港城护水行动

江苏海洋大学“林海相依”实践团社会实践成果网页。

页面记录盐城两日实践主线：黄海湿地博物馆参观与采访、竹林大饭店与盐镇水街城市文化体验、中华麋鹿园生境观察，以及景观湖和相邻排水沟的两份水样采集。

团队把现场见闻转化为一份可浏览、可互动、可分享的数字成果：

- 三张连云港在地照片，分别呈现近岸海域、校园周边公共活动水域和学校附近河道；
- “源头减量—岸带缓冲—生态净化—监测维护—公众参与”五步护水构想；
- 校园及城市小河、公共活动水域、沿海或感潮半咸水三类适配场景；
- pH、DO、氨氮、总磷、CODMn的指标互动展示；
- 连云港年度、规划背景与月度公开数据卡，以及石梁河、东海农田退水、赣榆“三池两坝一湿地”案例；
- 十余张来自团队实际行程的照片；
- GB 3838、人工湿地与河湖缓冲带指南等延伸资料。
